## How to read the statuses

| PARTIAL | Part of the capability works; the rest is explicitly not shipped. |

| UNAVAILABLE | Android or Play policy makes it impossible or dishonest to implement. |

## Product rules this matrix enforces

- A capability is never shown as protection before it ships: PLANNED rows have no UI and no code pointer.
- Nothing is claimed that Android cannot deliver (charging-current control, browser fingerprint spoofing, real-time install interception).
- Every implemented row names its code, its permissions, its data source, its limits and how it is verified.
- Cloud AI is deliberately absent; all analysis runs on the device.
